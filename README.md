## The entry

🌅 — the first sunrise over the open sea.

Not a generic beach: one specific, postcard-perfect moment. Dawn breaking
over the water on the first morning of the trip of a lifetime — the image
that makes a stranger want to book the flight.

## How it works

`main.py` (Python 3, standard library only, deterministic, no network)
writes exactly one emoji — U+1F305 SUNRISE, one character, 4 bytes UTF-8 —
to `/output/entry.txt`, per the program/v1 harness contract.

```sh
python3 main.py
```
